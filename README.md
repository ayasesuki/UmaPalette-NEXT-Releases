# Uma Prompt Palette NEXT

ウマ娘・キャラクターと衣装を選び、画像生成用プロンプトをコピーするWindows向けツールです。

## ダウンロード

**[0.5.2 テスト配布版をダウンロード](https://github.com/ayasesuki/UmaPalette-NEXT-Releases/releases/download/v0.5.2/UmaPalette_NEXT.zip)**（約108MB）

[リリース一覧](https://github.com/ayasesuki/UmaPalette-NEXT-Releases/releases)

## 起動方法

1. ZIPをダウンロードして「すべて展開」してください。
2. 展開したフォルダー内の `UmaPalette_NEXT.exe` を起動してください。
3. 詳しい操作方法は同梱の `はじめに.txt` を参照してください。

Windows 10 / 11の64bit（x64）版に対応しています。必要な.NET実行環境を同梱しています。

## 主な機能

- 人物・専用衣装・共通衣装のプロンプトコピー
- 名前、Danbooruタグ、血統、馬主、勝ち鞍などで検索・絞り込み
- `"red_hair"` のようなタグ完全一致検索と、髪色・瞳色・バストサイズの簡単検索
- お気に入り、タグ編集、バックアップ・復元、ダークモード

個人の編集や設定は初回起動時に作られる `userdata` に保存されます。
旧版から引き継ぐ場合は両方のアプリを終了し、旧版の `userdata` を新しいアプリの隣へコピーしてください。

このリポジトリでは完成アプリを配布しています。オンライン自動更新は未実装です。
